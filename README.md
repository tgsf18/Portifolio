## 🌟 Identidade Visual & Design System

- **Fundo Espacial (Galaxy & Stardust)**: Preto absoluto (`bg-black`) integrado com simulação profunda de galáxia, poeira estelar flutuante em desfoque e partículas cósmicas animadas via Canvas e CSS.
- **Estética Cromada Premium**: Botões, bordas dos cartões e elementos interativos principais simulam metal cromado reflexivo de alto brilho com gradientes metálicos intensos (`from-slate-400 via-zinc-100 to-zinc-500`), bordas semi-transparentes (`border-white/20`) e sombras brilhantes especulares.
- **Efeitos de Glassmorphism**: Caixas translúcidas com `backdrop-blur-md bg-zinc-950/40` flutuando sobre o fundo sideral.
- **Animações Fluidas com Framer Motion**: Animações de entrada suaves com desfoque (*blur reveal*), texto surgindo letra por letra, e transições de hover fluidas simulando um feixe de reflexo percorrendo o metal.
- **Responsividade Total**: Layout adaptativo fluido para dispositivos móveis, tablets e telas ultrawide sem quebra ou rolagem lateral.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- Node.js (versão 18 ou superior)
- npm ou yarn

### Instalação e Execução

```bash
# 1. Clone o repositório
git clone https://github.com/tgsf18/Portifolio.git

# 2. Acesse a pasta do projeto
cd Portifolio

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev

# 5. Para compilar a versão final de produção
npm run build
```
